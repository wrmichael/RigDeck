Frequency and mode follow the radio until you type a frequency or press SSB / CW; your choice is kept until the contact is logged. Frequency in MHz (14.250), kHz (14250) or Hz. Logbook

    

    

    

    
RigDeck remembers every contact it has sent to the logging program (Settings, "Send log to"). Back home from the field, press Send unsent and the contacts it has not sent yet go to the logger. With UDP, "sent" means it left the board; RigDeck cannot tell whether the logger was listening. TCP knows.

Recently deleted

    
DateUTCCallBandModeDeleted

    
Deleted contacts are kept here for 7 days. Restore puts a contact back where it was (current log, archive or both).

    
Every contact is written to two files: the current log and the archive. Clearing the current log leaves the archive untouched, so download the current log into your logging program, clear it, and the next download holds only new contacts. Edit or Delete fixes a contact in both files. Each station callsign has its own log: change the callsign in Settings and RigDeck switches to that station's files. Free space and "Erase all logs" are under Settings, Device.

  






  

    
CW trainer 

    

      
      
      
      
      
    

    
The trainer plays Morse in this browser; no radio is needed. "Spacing as" slower than the speed spreads the characters apart (Farnsworth).

    

      
    

  


  

    
Instant character recognition

    
One character at a time: type it as soon as you recognise it. RigDeck times each answer and plays your slow and missed characters more often. When every character in play is right 4 times out of the last 5 and quick, the next one is added.

    

      
      
      
    

    

    

    

  


  

    
Random groups

    
Groups from the characters in play on the Characters page. Copy them into the box, then Check.

    

    
    

  


  

    
Words

    
A word plays; type it and press Enter. A miss plays it again. Your own list: one word or phrase per line (or separated by commas).

    

      
      
      
    

    
    

    

  


  

    
Callsigns

    
Made-up callsigns from many countries, with portable and prefix forms now and then. Type each one and press Enter.

    

    

  


  

    
QSO copy

    
A made-up contact: a ragchew exchange or a contest-style one. Head-copy or write it down, then Show to compare.

    

    
    

  


  

    
Sending practice

    
Key with this page: straight key = hold the Space bar or the big pad; paddles = keys Z (dit) and X (dah), or the two pads (iambic). What you send is decoded below at the speed set above. To practise with the radio's own key or paddle, use Radio sidetone and key the radio with break-in off.

Choosing stations

      
      
Never answered or called, in any mode; a listed station that answers your CQ is ignored. W1ABC also covers W1ABC/P and VE3/W1ABC; XX9* covers every call that starts with XX9. Commas or spaces between calls.

      
      
      
    
        
    When several stations call you (Auto CQ) or call CQ (Auto hunt), the first rule that tells them apart decides; ties go to the next rule, then to the first one heard. The do-not-work list is applied first.

    Map on the touch screen: …
        
    
        
    The APRS map (countries, states, lakes, US counties and highways; Natural Earth 1:10m, about 3.5 MB) is kept on the microSD card, once. Ways to get it there: the Get map button on the APRS screen when RigDeck is on a home network with internet; Get the map from the RigDeck site here, when this browser has internet; Load a map file with rigdeck-map.rdm downloaded earlier; or copy that file into the RigDeck folder on the card and restart. Without it the APRS screen shows rings and stations only.

    Home network: …  
    The home network must be 2.4 GHz. It is joined right away; no restart needed.
    
    
    
    
    
    
    Hotspot name/password, CI-V baud and GPS changes take effect after a restart; the home network is joined right away.
    
    
    Wi-Fi chip
    
    
    Firmware: …
    
    
    
    
    Updates the firmware of the board's Wi-Fi chip with rigdeck-wifi-chip.bin (from the RigDeck release, or build it with build_wifi_chip.bat). Join the RigDeck hotspot and use 192.168.4.1 for this, keep the board powered, and allow about a minute. The chip keeps its old firmware unless the new one arrives complete, and RigDeck restarts when it is done.
    
    
    Update RigDeck
    
    
    
    
    
    
    
    
    
    
    Updates RigDeck over Wi-Fi, no USB cable needed. The internet buttons need this browser to be online (the board on your home network). Or download rigdeck-x.y.z.bin from the flasher page and install the file. RigDeck stops transmitting, keeps its settings and logs, and restarts when done (about a minute). If the new version does not start properly, the board goes back to the one it had.
    
    
    Device
    
    
    
    
    
       
       
    
    
    
    Brightness changes at once. Contrast (100 % = normal) applies after a restart.
    
    
    Logbook (contacts) and storage
    
    
    
    
     
    
    
    With a microSD card (FAT32) in at start-up the logs live on the card, in the RigDeck folder, one set of files per station callsign (e.g. AC9HP_log.adi, AC9HP_archive.adi). Contacts logged in the board's memory move onto the card at that start. On the card, deleted contacts are kept for good in AC9HP_deleted.adi and a cleared current log is kept as AC9HP_deleted_date_time.adi. Insert or remove the card with the power off.
    
    
    Console logs (for troubleshooting)
    
    
    
    
    
    
    Radio diagnostics
    
    
      
    
    
     
    
    
     
    
    
    
    
    The recent log is the last 128 kB of the console, kept in memory even without a microSD card. The USB report lists every USB device with its descriptors and the radio sound chip's volume, mute and mixer controls. CAT messages are logged around every transmission; the trace button logs all of them for two minutes. "Send to radio" sends one CAT command (CI-V radios: hex bytes) and shows what came back. The sound chip line reads a control, or sets it when a value is given: unit and channel as in the USB report; cs 1 = mute (0/1), cs 2 = volume in 1/256 dB (0 = 0 dB, -2560 = -10 dB); for a mixer unit (MU), cs = input channel and ch = output channel.
    
    
    Settings file
    
    
    
    
    
      
    Changes in the file. Ticked ones are applied; things that belong to this unit (its name, hotspot, home network, TX levels, offsets, screen) start unticked.
    
      
    SettingNowFrom the file
    
      
    
    
    
    
    Export saves every setting except passwords as a text file named after this RigDeck. Import it on another RigDeck to copy the station setup; you see each change before it is applied.
    
    
    Clock
    
    
    
    
    Without internet or GPS the clock follows this browser's clock each time the page is open. If most stations show the same DT offset, nudge the clock until DT is near zero. With GPS on, change "GPS sentence delay" instead: lower it if DT values are mostly negative, raise it if they are mostly positive.
